# Decision records

One file per decision that shaped the project: the problem, what else was considered,
what was chosen, and what it costs. They answer **why**, where `ARCHITECTURE.md`
answers **how** and `docs/status/` answers **what is finished**.

A record is written when a decision is *closed* — not while it is being argued. Once
written it is not edited except to add consequences discovered later, or to mark it
superseded by a higher-numbered record. That is the point: a decision log you rewrite
is just documentation.

Dates are the day the decision was made, where that is known. Anything predating the
status log says so rather than guessing.
